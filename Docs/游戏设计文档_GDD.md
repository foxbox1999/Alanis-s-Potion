## 1. 游戏概述

### 1.1 一句话简介

在猎巫时代隐姓埋名的游医艾拉妮丝，在小镇经营药铺：采集药材、炼制药品、为镇民看病、养育养子、与 NPC 建立关系，并在一段中世纪魔幻剧情中寻找自己的位置。

### 1.2 类型与平台

| 项目 | 内容 |
|---|---|
| 类型 | 2D 模拟经营 + 叙事 RPG |
| 玩法标签 | 采集、炼药、看病、养成、社交、剧情、多结局 |
| 平台 | PC（Windows）优先 |
| 视角 | 2D 俯视 / 横版场景 + 全屏 UI |
| 付费模式 | 买断制（建议定价 50 元左右） |
| 目标时长 | 单周目 6–10 小时 |
| 引擎 | Unity + C# |

### 1.3 目标用户与画像

目标用户是喜欢故事性、解密向、经营养成的玩家。他们通常有固定的游戏时间（下班/放学后 1–2 小时），希望游戏能提供『有温度、能沉浸、每天有事做』的体验，而不是高强度操作或竞技对抗。

| 维度 | 描述 |
|---|---|
| 年龄 | 16–35 岁为主 |
| 性别 | 相对均衡 |
| 游戏习惯 | 每天 1–2 小时，偏好单机、剧情、养成 |
| 核心诉求 | 有温度、能沉浸、每天有事做 |
| 参考作品 | 《林中小女巫》《火山的女儿》 |

### 1.4 核心体验三支柱

1. **经营成就感**：玩家从一无所有开始，逐渐把药铺经营起来，看着病人络绎不绝、银币稳定增长，获得『我把店开起来了』的成就感。
2. **叙事沉浸感**：在猎巫背景下隐藏身份，每一次行医都是冒险；与镇民建立关系、做出选择，最终走向不同结局。
3. **养成陪伴感**：养子从懵懂幼体逐步成长，玩家每天的安排都会体现在他的属性与对话上，形成长期的情感投射。

### 1.5 设计基调

- **轻中度**：单局节奏舒缓，不追求高强度操作，适合碎片时间游玩。
- **正反馈密集**：采集有收获、炼药有成品、看病有收入、养子有成长，每一步都有明确反馈。
- **选择有代价**：救人会提升暴露风险，送礼会消耗资源，养成有取舍。
- **叙事驱动**：用剧情和 NPC 关系把各系统串起来，避免『纯刷数值』的空洞感。

### 1.6 与同类作品的差异

| 对比项 | 本作 | 同类作品 |
|---|---|---|
| 核心冲突 | 救人 vs 暴露身份 | 多为纯经营或纯养成 |
| 玩法融合 | 采集+炼药+看病+养成+社交 | 多为单一玩法 |
| 叙事压力 | 怀疑度会触发坏结局 | 多为线性剧情 |

## 2. 世界观与剧情

### 2.1 背景设定

西罗马帝国灭亡后至十五世纪，欧洲进入中世纪。小部分人类魔力觉醒，在主教指示下『猎巫行动』开始，数十万人被指为异端、巫师而惨死。巫师们抱团取暖，形成自己的协会。

这个设定决定了游戏的核心张力：

- 主角是『有魔力的人』，天然是猎巫对象；
- 主角又是『医生』，必须接触大量镇民；
- 每一次行医都是一次暴露风险的累积。

### 2.2 主角设定

主角是一位突然觉醒魔力的普通女性。在家人的巨大牺牲下，她逃脱了一次猎巫行动，隐居山岭百年，之后以流浪医生的身份来到小镇，帮助镇民祛除病症。

**核心矛盾**：主角必须隐藏自己的巫师身份，同时用魔药救人——救人越多，暴露风险越高。

**人物弧光**：从『只想隐藏』到『愿意为镇民承担风险』，最终在结局中面对自己的身份。

### 2.3 养子设定

主角的养子是一只白毛蓝眼的恶魔（幼体），需要玩家每日安排课程与探索，逐步成长。养子的成长与主角的处境、结局相互影响。

**情感作用**：养子是玩家在异乡唯一的『家人』，是玩家每天回药铺的情感锚点。

### 2.4 主线脉络

1. **序章**：主角逃亡、隐居、来到小镇。
2. **立足**：盘下药铺、认识镇民、开始行医。
3. **发展**：采集炼药、看病赚钱、养育养子、建立关系。
4. **转折**：身份暴露的危机、教会与巫师协会的冲突。
5. **结局**：根据玩家行为走向不同结局。

### 2.5 结局设计

| 结局 | 触发条件 | 简述 |
|---|---|---|
| 隐居结局 | 身份未暴露 + 养子成长达标 | 平静生活，与养子相守 |
| 暴露结局 | 怀疑度过高 | 被教会发现，被迫再次逃亡 |
| 协会结局 | 与巫师协会关系深 | 加入协会，成为其中一员 |
| 第五天结局 | 剧情推进到特定节点 | 阶段性结局/序章收束 |

### 2.6 剧情节奏

| 阶段 | 内容 | 目标 |
|---|---|---|
| 第 1 天 | 序章 + 捏脸 + 进镇 + 回药店 | 建立基本认知 |
| 第 1–3 天 | 采集/炼药/看病/养子教学 | 形成每日循环 |
| 第 3–5 天 | 关系建立、剧情推进、第一个转折 | 产生情感投入 |
| 第 5 天后 | 自由游玩，向结局收束 | 完成叙事闭环 |

### 2.7 剧情摘要（示例）

**序章**：雨夜，主角带着养子逃到小镇，在药铺门前停下。她决定以医生身份留下，用医术换取立足之地。

**立足**：她盘下旧药铺，认识甜品店长苏珊、收租人维戈、以及几个镇民。第一笔生意是给发烧的孩子看病，她用自制的退烧药治好了孩子，赢得了信任。

**发展**：病人越来越多，她开始采集、炼药、扩大经营；养子也在每日的课程中成长。但教会的人开始注意到这个『医术高明的外乡人』。

**转折**：一次误诊让病人病情加重，怀疑度上升；教会开始调查。主角必须在『继续救人』与『保护自己』之间抉择。

**结局**：根据怀疑度、与协会的关系、养子成长，走向隐居/暴露/协会等结局。

## 3. 核心玩法循环与玩家旅程

### 3.1 日循环

```
起床(8:00) -> 安排养子任务 -> 出门采集/看病/炼药/社交
-> 傍晚回药铺 -> 结算当日 -> 23:50 强制休息 -> 次日
```

每天玩家的『决策点』：

1. 养子今天上什么课 / 去哪探索？
2. 今天先采集还是先看病？
3. 要不要花时间来炼药（等待时间）？
4. 要不要送礼 / 和谁对话？
5. 要不要接某个病人（可能失败、增加怀疑度）？

### 3.2 经济循环

```
采集(免费) -> 炼药(耗材料) -> 看病(用药品) -> 赚银币
-> 买材料/礼物 -> 提升关系 -> 解锁剧情与更好的药方
```

### 3.3 成长循环

```
每日安排养子任务 -> 次日结算属性 -> 属性达标解锁剧情/能力
```

### 3.4 叙事循环

```
与 NPC 对话/送礼 -> 好感度/怀疑度变化 -> 解锁新对话 -> 推进主线
```

### 3.5 循环咬合

- 采集产出材料 → 炼药消耗材料 → 看病消耗药品；
- 看病赚钱 → 买礼物 → 提升关系 → 解锁剧情；
- 养子属性 → 影响探索收益与剧情；
- 剧情推进 → 解锁新区域/新药方/新对话。

### 3.6 玩家旅程（第一天到第五天）

**第一天**：

1. 播放序章对话（纯背景）。
2. 进入捏脸，选择主角外观。
3. 第二段剧情，进镇。
4. 第三段剧情，盘下药铺。
5. 回药店，HUD 教学。
6. 自言自语，进入自由活动。
7. 采集教学：去采集一次。
8. 炼药教学：按引导炼一锅退烧药。
9. 回到主菜单，养子教学（安排第一天任务）。
10. 休息到次日。

**第二天**：

1. 起床，看到养子任务结算。
2. 病人开始上门，尝试看病。
3. 采集、炼药、看病形成循环。
4. 出门认识更多 NPC。

**第三到五天**：

1. 关系深化，出现分支对话。
2. 怀疑度逐渐累积，出现危机事件。
3. 养子成长，解锁新能力。
4. 第五天触发阶段性结局。

### 3.7 首小时体验设计

第一小时是决定玩家是否留存的关键，目标：让玩家在 60 分钟内完整体验一次『采集→炼药→看病』的闭环，并获得第一次收入。

| 时间 | 内容 |
|---|---|
| 0–10 分钟 | 序章对话 + 捏脸 |
| 10–20 分钟 | 进镇剧情 + 盘店 |
| 20–30 分钟 | HUD 教学 + 自由活动 |
| 30–40 分钟 | 采集教学 |
| 40–50 分钟 | 炼药教学 |
| 50–60 分钟 | 第二段剧情 + 第一个病人 |

### 3.8 长期留存设计

- 每日任务：养子安排、病人清单，给玩家『明天还要来』的理由。
- 关系成长：每天对话/送礼推进好感度，解锁新剧情。
- 目标感：怀疑度/交租/结局条件，让玩家有长期目标。
- 收集：情报图鉴、药方收集、结局收集。

## 4. 系统设计（详规）

### 4.1 采集系统

**设计目标**：给玩家稳定的原材料来源，同时把玩家『送出门』，接触世界与 NPC。

**流程**：

1. 玩家在主菜单或 HUD 点击『采集』。
2. 打开采集界面，显示四个采集区域按钮。
3. 点击某区域，淡入显示该区域可采草药面板（图标 + 名称 + 数量范围）。
4. 点击『确认采集』，关闭面板、播放采集动画。
5. 动画结束，结算随机数量的草药，加入背包。
6. 推进游戏时间（2–4 小时），弹出获得物品提示。

**规则**：

- 4 个区域，每区独立草药池（按 Herb.zoneIds 匹配）。
- 每次数量在 `[minQuantity, maxQuantity]` 随机。
- 采集消耗 2–4 游戏小时。
- 教学阶段（PlotStep 9）引导首次采集。

**区域表**：

| 区域 | 草药倾向 | 解锁条件 |
|---|---|---|
| Petran Mountain | 常见草药 | 默认解锁 |
| Theslam Wilds | 中等草药 | 默认解锁 |
| Hissing Forest | 稀有草药 | 剧情解锁 |
| Rare Mound Thicket | 稀有草药 | 剧情解锁 |

**边界情况**：

- 区域无草药时提示『该区域暂无可采集草药』。
- 采集动画期间禁用其他交互。
- 背包满时提示（若后续加入容量限制）。

**设计理由**：采集是最基础的资源获取方式，必须『零门槛、有反馈、能推动时间』，让玩家愿意每天做。

**体验目标**：让玩家感受到『出门采集』是每日固定节奏。

### 4.2 炼药系统

**设计目标**：把材料转化为药品，制造『等待』与『规划』的节奏。

**流程**：

1. 玩家打开炼药界面，书本显示药方列表。
2. 点击某药方，书页翻到配方详情（成品、材料、数量、时间）。
3. 若材料足够，点击『开始炼制』。
4. 书本向右平移（旋转到炼制状态），扣除材料，创建任务。
5. 播放勺子/蒸汽动画，显示倒计时。
6. 倒计时结束，书本保持打开位，弹出领取弹窗。
7. 确认弹窗，发放药品，书本归位。

**规则**：

- 配方由 Potion.recipe 定义（材料 + 时长）。
- 开始扣除材料，创建任务（剩余真实秒数）。
- 炼药期间按钮禁用；退出再回，倒计时继续。
- 完成时书本保持打开位，弹窗领取；确认后归位发药。
- 同一时间只能炼一锅。

**界面构成**：书籍（左选药方、右看配方）、药方列表（分页/图标/库存）、配方详情（成品/材料/需求/持有）、倒计时、开始按钮、炼药动画。

**边界情况**：材料不足禁用/提示；已在炼制提示；完成但不在界面时回界面再弹窗。

**设计理由**：炼药是核心的『生产』环节，必须有明确的投入产出和等待感，才能让玩家规划时间。

### 4.3 看病系统

**设计目标**：核心收入来源 + 与 NPC 建立关系的入口 + 叙事张力的来源。

**流程**：

1. 病人上门（每天 0–3 个），在诊所界面显示病人列表。
2. 选择病人，查看立绘与症状线索。
3. 通过『望闻问切』发现症状（口述/可见）。
4. 根据症状筛选匹配的药品。
5. 选择药品治疗，结算结果。
6. 成功：病人痊愈、给钱、好感度略升；失败：赔钱、怀疑度上升。

**规则**：

- 每天 0–3 个病人；有名字 NPC 10% 概率成为病人。
- 病人有等待天数，超时 Gone。
- 成功：+药价×1.1；失败：-药价×0.5 且 +怀疑度。
- 没药：Deferred，次日再来。

**界面构成**：病人列表、病人立绘、症状线索（口述/可见）、药品筛选、治疗按钮、结算反馈。

**边界情况**：多次误诊大幅提升怀疑度；有名字 NPC 成为病人时结果影响好感度。

**设计理由**：看病是『诊断推理』的核心，玩家要根据症状判断病症、选择药品；同时失败会提升怀疑度，形成『救人 vs 暴露』的张力。

### 4.4 养成系统

**设计目标**：长期目标 + 情感投射。

**流程**：

1. 打开养子界面，看到养子立绘与四维属性。
2. 选择时段（上午/中午/下午）。
3. 为该时段选任务（课程/探索）。
4. 三个时段都安排完，点击确认。
5. 次日结算属性成长与探索收获。

**规则**：

- 课程提升魔法/魔药/常识/耐力。
- 探索去指定区域采集。
- 三个时段排满才能确认。
- 属性达标解锁剧情/能力。

**课程表**：

| 课程 | 属性 | 说明 |
|---|---|---|
| 魔法课 | 魔法 | 解锁魔法剧情 |
| 魔药课 | 魔药 | 提升炼药效率 |
| 常识课 | 常识 | 解锁对话选项 |
| 耐力课 | 耐力 | 提升探索收益 |

**边界情况**：第一天禁用；未安排时出门被提示。

**设计理由**：养子需要『每天照顾』的仪式感，属性成长要给玩家长期目标。

### 4.5 社交与情报

**设计目标**：让 NPC 有记忆，把关系做成可感知的数值。

**规则**：好感度（对话/送礼）、怀疑度（误诊/可疑行为）、认识（首次对话）。情报按阵营（村民/巫师/教会）分页。

**界面**：阵营切换、NPC 列表（头像/名字/数值）、详情页（背景/偏好/性格）、红绿点指示。

**边界情况**：怀疑度过高触发暴露结局；未认识 NPC 不显示情报。

**设计理由**：关系数值让玩家的行为有『长期后果』，是叙事与玩法结合的纽带。

### 4.6 背包与商店

**设计目标**：让玩家有整理与取舍的经营感。

**背包**：分类展示、选择（送礼/出售）、出售。**商店**：甜品店（礼物）、草药店（材料）。

**规则**：分类分页、选中显示详情、出售按价格折算、购买扣银币加背包。

**边界情况**：银币不足提示；背包满提示。

### 4.7 捏脸系统

**设计目标**：让玩家自定义主角外观，增强代入感。

**流程**：

1. 打开捏脸界面，显示部位与颜色选项。
2. 选择发型/眼睛/眉毛/嘴 + 颜色。
3. 确认，运行时合成主角立绘。
4. 对话中主角用『nielian』表情显示合成立绘。

**规则**：部位若干样式/颜色；确认后发布事件、保存部位标识、合成 Sprite。

**边界情况**：合成贴图需 Read/Write；重复合成要销毁旧纹理。

<!-- 配图说明：这里插入「捏脸界面截图」 -->

### 4.8 剧情与对话

**设计目标**：承载叙事，驱动玩家前进。

**规则**：CSV 驱动，分支选项 + 效果指令（认识/好感度/银币/金币/打开商店/随机物品）；PlotStep 推进；关键节点触发教程/场景切换。

**界面**：背景图、左右立绘、对话框（名字+内容+逐字）、选项按钮、跳过按钮。

**边界情况**：跳过时仍触发『认识』等副作用；选项行不触发副作用。

**设计理由**：对话是叙事的主要载体，必须支持分支与效果，让玩家的选择有结果。

### 4.9 引导系统

**设计目标**：降低新手门槛。

**规则**：按目标 UI 名定位、箭头+文字、点击遮罩推进、关键节点强制引导（HUD/采集/炼药/养子/看病/地图）。

**设计理由**：模拟经营系统多，新玩家容易迷路，引导是留存的关键。

### 4.10 地图与场景

**设计目标**：让玩家在小镇里有空间感与探索欲。

**规则**：HUD 打开地图、选区域黑屏传送、场景内点建筑进界面、未开放提示。

## 5. 数值与平衡

### 5.1 货币

| 货币 | 初始 | 来源 | 用途 |
|---|---|---|---|
| 金币 | 10 | 剧情/特殊 | 高级物品 |
| 银币 | 100 | 看病/出售 | 买材料/礼物/交租 |

### 5.2 看病收益

| 结果 | 银币变化 | 怀疑度 |
|---|---|---|
| 治疗成功 | +药价 × 1.1 | 0 |
| 用错药 | -药价 × 0.5 | +10 |
| 没药 | 0 | 0（Deferred） |

### 5.3 好感度 / 怀疑度

- 好感度：对话 +5、送礼 +10（示例）。
- 怀疑度：用错药 +10、可疑行为增加。
- 阈值：怀疑度过高触发暴露结局。

### 5.4 时间与交租

- 游戏时间倍速 12 倍（1 游戏天 = 2 现实小时）。
- 每日 23:50 强制休息，跳次日 8:00。
- 交租每 90 天一次。

### 5.5 养子属性

| 属性 | 提升方式 | 作用 |
|---|---|---|
| 魔法 | 课程 | 解锁魔法剧情 |
| 魔药 | 课程 | 提升炼药效率 |
| 常识 | 课程 | 解锁对话选项 |
| 耐力 | 课程 | 探索收益 |

### 5.6 采集数量

- 每种草药 min~max 随机；消耗 2–4 游戏小时。

### 5.7 数值目标

- 第 1–2 天：能完成基础循环，不卡资源。
- 第 3–5 天：开始有取舍（先看病还是先采集）。
- 第 5 天后：向结局收束，数值不再大幅增长。

### 5.8 平衡检查清单

- 玩家是否会在第 1 天卡材料？
- 玩家是否会在第 3 天钱太多/太少？
- 误诊的惩罚是否过重/过轻？
- 养子成长速度是否匹配剧情节点？

1. 根界面切换用黑屏转场，普通面板淡入淡出，弹窗不黑屏。
2. 返回优先级：先内部返回（详情→列表），再弹栈回上一级。
3. 重要操作二次确认。
4. 反馈及时：音效 + 提示。
5. 减少双击：能单击完成的不要双击。
6. 图标配文字：返回/主页加字区分。

### 6.3 引导设计

- 首次进入系统触发引导。
- 箭头指向具体按钮，文字说明作用。
- 点击遮罩推进。
- 覆盖 HUD/采集/炼药/养子/看病/地图。

### 6.4 视觉层级

- ScreenUI：普通界面。
- TopLayer：对话/弹窗/引导/提示。
- 黑屏层：最高。

### 6.5 分辨率适配

- 设计基准 1920×1080。
- CanvasScaler：Scale With Screen Size + Match 0.5。
- 贴边元素用锚点贴边。

### 6.6 各界面线框要点

- 主菜单：六个大按钮（采集/看病/炼药/背包/养子/出门）+ 顶部日期/货币。

- 养子：立绘 + 四维属性 + 三时段 + 任务按钮。
- 情报：阵营切换 + NPC 列表 + 详情。

## 21. 经济模型详解

### 21.1 每日收支预估（第 2–3 天）

| 项目 | 收入/支出 | 说明 |
|---|---|---|
| 采集 | 0 | 免费，但消耗时间 |
| 炼药 | -材料 | 材料来自采集，折算约 10–20 银币 |
| 看病成功 | +20~40 银币 | 每次成功 |
| 买礼物 | -8~15 银币 | 送礼用 |
| 交租 | -（90 天一次） | 长期压力 |

### 21.2 价格梯度

| 档次 | 药品售价 | 对应病症 |
|---|---|---|
| 低 | 15–25 | 常见小病 |
| 中 | 30–45 | 中等病症 |
| 高 | 60+ | 重症/强化药 |

### 21.3 经济循环平衡

- 采集 1 次约得 3–6 份材料，够炼 1–2 锅。
- 1 锅药 → 1 次看病 → 20~40 银币。
- 1 天做 2–3 次循环，收入约 40–120 银币。
- 礼物 8–15 银币，确保玩家能负担每日送礼。

### 21.4 通胀控制

- 后期药价上涨但材料也更稀有，避免玩家无脑刷钱。
- 交租作为长期消耗，平衡后期收入。

## 23. 完整对话脚本示例

以下是一段『第一次见到苏珊』的完整对话脚本（CSV 形式）：

```
#,166,甜品店长,normal,好的，改主意了随时来买吧，我们家的甜品绝不会让你失望的。,167,,
END,167,,,,,,
#,168,甜品店长,normal,你要买吗？,169,,
&,169,,,买,174,打开商店@甜品,
&,170,,,闲聊,171,,
#,171,甜品店长,normal,我是苏珊，你叫什么啊？这个时间点来旅游的人可不多见。,172,认识@Susan,
#,172,艾拉妮丝,nielian,我是艾拉妮丝，其实我是游医，机缘巧合下来这里开店了。,173,,
#,173,苏珊,normal,原来如此，那之后就拜托你啦。,174,,
END,174,,,,,,
```

说明：

- 168 是入口，展示『你要买吗』。
- 169/170 是选项：买 → 打开商店；闲聊 → 认识苏珊。
- 171 带『认识@Susan』效果，首次对话后苏珊加入情报。
- 172/173 是后续对白。

## 27. 玩家成长路径

### 27.1 前期（第 1–3 天）

- 目标：熟悉系统、完成第一次完整循环。
- 关键节点：采集教学、炼药教学、第一个病人。
- 玩家感受：『我学会了怎么经营这家店』。

### 27.2 中期（第 3–10 天）

- 目标：扩大经营、建立关系、推进剧情。
- 关键节点：认识更多 NPC、解锁新药方、养子成长。
- 玩家感受：『我的店越来越好了，我也有了朋友』。

### 27.3 后期（第 10 天后）

- 目标：面对危机、走向结局。
- 关键节点：怀疑度危机、教会调查、结局分支。
- 玩家感受：『我必须做出选择』。

## 30. 设计决策记录（为什么这样设计）

### 30.1 为什么要做『怀疑度』？

让经营与叙事绑定：玩家不是无脑赚钱，而是要在『救人』与『自保』之间权衡。这是本作区别于普通模拟经营的核心。

### 30.2 为什么炼药要等待？

制造节奏与规划：玩家不能无限刷药，必须规划时间（采集/看病/炼药），让每天都『有事可做但有取舍』。

### 30.3 为什么养子要每天安排？

提供每日仪式感与情感投射：玩家每天回药铺的第一件事是安排养子，形成习惯与羁绊。

### 30.4 为什么用 CSV 驱动剧情？

降低内容制作成本：策划可以直接编辑 CSV，不用改代码，便于快速迭代大量剧情。

## 32. 难度曲线与动态调整

### 32.1 难度来源

- 病人病情复杂度（症状数量、易混淆程度）。
- 材料获取难度（稀有草药所在区域）。
- 怀疑度压力（误诊惩罚）。
- 时间压力（每日时长、交租）。

### 32.2 难度曲线

| 阶段 | 难度 | 调整 |
|---|---|---|
| 前期 | 低 | 常见病、材料充足 |
| 中期 | 中 | 出现混淆症状、稀有材料 |
| 后期 | 高 | 重症、高风险、双线压力 |

### 32.3 动态平衡手段

- 若玩家连续误诊，降低后续病人难度（保底体验）。
- 若玩家收入过高，提高稀有材料消耗。
- 若玩家长期不推进剧情，用事件提示。

## 33. 常见问题与设计边界

### 33.1 玩家可能问的问题

**Q：我不知道该做什么？**
A：主菜单有明确的功能入口，引导会提示下一步；HUD 显示日期与目标。

**Q：钱不够怎么办？**
A：多采集、多炼药、多看病；也可以出售背包多余物品。

**Q：怀疑度太高了怎么办？**
A：减少误诊、少接触教会、推进协会线；慎用高风险药方。

**Q：养子有什么用？**
A：属性成长解锁剧情与能力，是长期目标与情感线。

### 33.2 设计边界

- 不做多人/联机。
- 不做高强度动作/战斗。
- 不做复杂经济模拟（股票/贸易）。
- 聚焦『经营 + 叙事 + 养成』三角。
